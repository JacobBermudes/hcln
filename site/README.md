# CLEAN OFFICE — сайт

Статический сайт на Astro. Структура и тексты — из базы знаний в корне проекта
(`03-struktura-sajta-i-poryadok-blokov.md`, `04-kontent-i-teksty.md`),
оформление — из макета «Чистота» (Figma Community).

## Запуск

```bash
npm install
npm run dev        # http://localhost:4321
```

## Сборка и выкладка

```bash
npm run build      # готовый сайт складывается в dist/
npm run preview    # посмотреть собранное локально
```

В `dist/` лежит обычный статический сайт: HTML, CSS, JS, картинки. Ни Node,
ни базы данных, ни лицензий на сервере не нужно.

**Куда выкладывать.** Любой российский шаблонный хостинг с PHP: Timeweb,
Beget, REG.RU, Sprinthost. Содержимое `dist/` заливается в `public_html`
по FTP или git-деплоем. Дата-центры в РФ, бесплатный SSL и HTTP/2 входят
в тариф — этим закрываются требования ТЗ §10 и 152-ФЗ.

Порядок первой выкладки:

1. Залить содержимое `dist/` в корень сайта.
2. Проверить, что `.htaccess` и `form.php` попали в корень (это скрытый файл —
   в FTP-клиенте включите показ скрытых файлов).
3. Открыть `form.php` и заполнить константы: токен Telegram-бота, chat_id,
   почту, вебхук CRM.
4. Отправить тестовую заявку с сайта и убедиться, что она пришла.
5. В `astro.config.mjs` заменить `SITE` на боевой домен, пересобрать.
6. В `public/robots.txt` заменить `hcln.ru` на боевой домен.
7. Отправить `sitemap-index.xml` в Яндекс.Вебмастер и Search Console.

## Картинки

Три скрипта готовят изображения из папок в корне проекта:

```bash
npm run images   # ../reference  → фотографии-заглушки, кроп из скриншотов Pinterest
npm run logos    # ../case       → логотипы клиентов
npm run brand    # ../brand      → брендированный автомобиль для первого экрана
npm run assets   # всё сразу
```

Результат складывается в `public/img/`. Пересобирать нужно только после
замены исходников.

## Где что править

| Что | Файл |
|---|---|
| Телефон, почта, часы работы, реквизиты | `src/data/site.ts` |
| Цифры-заглушки (лет на рынке, объектов, ₽/м²) | `src/data/site.ts`, блок `PLACEHOLDERS` |
| 11 услуг: тексты, цены, состав работ, FAQ | `src/data/services.ts` |
| Кейсы, отзывы, тарифы, гарантии, FAQ главной | `src/data/content.ts` |
| Коэффициенты калькулятора | `src/data/calculator.ts` |
| Цвета, шрифты, отступы, скругления | `src/styles/tokens.css` |

`src/data/services.ts` — единственный источник правды по услугам: из него
собираются мегаменю, плитка на главной, колонка в футере и страницы услуг.

## Перед публикацией

Данные, которые нельзя публиковать в текущем виде:

- **Цифры рядом с реальными названиями клиентов.** Логотипы Брусники, Динамо
  и Классиков настоящие, а площади, сроки и результаты в карточках кейсов —
  примеры формулировок. В тексте они помечены как `{{площадь}}` и `{{срок}}`.
- **Отзывы** подписаны «Пример отзыва» — заменить на реальные.
- **Реквизиты** в футере и блоке «Работаем официально» — плейсхолдеры.
- **Пары «до / после»** собраны из разных кадров. Документ 07 требует
  одинаковый ракурс в паре, иначе сравнение не читается.
- **Фотографии** — временные, вырезаны из скриншотов. Для блоков «Команда»,
  «Кейсы» и «Отзывы» сток недопустим, нужна фотосессия.
- Нужно **письменное согласие клиентов** на публикацию логотипов.

Полный список открытых вопросов — в `../OPEN-QUESTIONS.md`.
