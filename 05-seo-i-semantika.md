## 1. Первоочередное: снять блокировку

Текущее состояние — сайт закрыт от индексации, `robots.txt` принадлежит другому
проекту. Порядок действий:

1. Залить исправленный `robots.txt` (лежит в этой папке) на боевой домен.
2. Сгенерировать `sitemap.xml`, указать в нём только боевой домен, добавить
   `<lastmod>`.
3. Проверить в Яндекс.Вебмастере: «Инструменты → Анализ robots.txt» и
   «Индексирование → Переобход страниц» — отправить главную и все страницы услуг.
4. То же в Google Search Console: проверка URL → запросить индексирование.
5. Закрыть тестовый домен `hcln.test-1pos.ru` **HTTP-авторизацией** (не robots —
   robots не мешает индексации по внешним ссылкам). Если домен уже
   проиндексирован — 301 на боевой.
6. Прописать `<link rel="canonical">` на каждой странице с абсолютным URL
   боевого домена.
7. Проверить, что боевой домен доступен только в одном варианте: `https://`,
   без `www` (или с — но один), остальные — 301.

Ожидаемый эффект: страницы начнут появляться в выдаче через 1–4 недели.

## 3. Структура URL

Правила:
- латиница, транслитерация, дефисы вместо подчёркиваний;
- всё в нижнем регистре;
- конечный слеш — одинаково на всём сайте;
- вложенность не больше 3 уровней;
- без дат, без ID, без параметров в индексируемых URL.

**Текущие URL и что с ними делать:**

| Сейчас | Должно быть | Действие |
|--------|-------------|----------|
| `/uborka-office/` | `/uslugi/uborka-ofisa/` | 301 |
| `/uborka-ofisov/` (это гостиницы!) | `/uslugi/uborka-gostinic/` | 301, **исправить путаницу** |
| `/uborka-magazinov/` | `/uslugi/uborka-magazina/` | 301 |
| `/uborka-torgovyix-czentrov-i-biznes-czentrov/` | `/uslugi/uborka-tc-i-bc/` | 301 |
| `/uborka-salonov-krasotyi/` | `/uslugi/uborka-salonov-krasoty/` | 301 |
| `/uborka-skladov/` | `/uslugi/uborka-skladov/` | 301 |
| `/uborka-restoranov-i-kafe/` | `/uslugi/uborka-restoranov/` | 301 |
| `/uborka-fitnes-centrov-i-sportivnyh-kompleksov/` | `/uslugi/uborka-fitnes-centrov/` | 301 |
| `/uborka-zhk-i-podezdov/` | `/uslugi/uborka-zhk/` | 301 |
| `/myite-okon/` | `/uslugi/mojka-okon-i-fasadov/` | 301 |
| `/ximchistka-mebeli/` | `/uslugi/himchistka-mebeli/` | 301 |
| `/kontaktyi/` | `/kontakty/` | 301 |
| `/generalnaya-uborka/` | `/uslugi/uborka-ofisa/generalnaya/` | 301 |
| `/regulyarnaya-uborka/` | `/uslugi/uborka-ofisa/regulyarnaya/` | 301 |
| `/posle-remonta/` | `/uslugi/uborka-ofisa/posle-remonta/` | 301 |

**Отдельно отметить:** сейчас страница `/uborka-ofisov/` — это «Уборка гостиниц
и отелей», а `/uborka-office/` — «Уборка офиса». Два почти одинаковых URL с
разным содержанием — источник путаницы и для поисковика, и для пользователя.
Обязательно развести.

**Правило переезда:** все старые URL закрываются 301-редиректом на новые,
цепочек редиректов (301 → 301 → 200) быть не должно. Карту редиректов
подготовить до переноса, проверить после — все старые адреса отдают 301,
а не 404.

## 4. Микроразметка Schema.org

| Тип | Где | Что даёт |
|-----|-----|----------|
| `Organization` + `LocalBusiness` | все страницы | Карточка организации, гео, часы, телефон |
| `BreadcrumbList` | все внутренние | Хлебные крошки в сниппете |
| `Service` | каждая страница услуги | Понимание тематики, связь с ценой через `offers` |
| `Offer` с `priceSpecification` | страницы услуг | Цена в сниппете. **Только с реальной ценой**, пустой `price` — ошибка |
| `FAQPage` | главная + страницы услуг | Расширенный сниппет с вопросами — заметно повышает CTR |
| `ImageObject` | галерея до/после | Поиск по картинкам |
| `Review` / `AggregateRating` | страница отзывов | Звёзды в сниппете. Только реальные отзывы, иначе санкции |

Убрать: текущий `schema.org/Product` с пустой ценой — он даёт ошибку валидации.

Проверка: валидатор Яндекса (Вебмастер → Инструменты → Валидатор
микроразметки) и Google Rich Results Test.

## 5. Локальное SEO — по важности выше половины работ по сайту

Для Екатеринбурга справочники дают значительную часть коммерческих обращений.

**2ГИС** — приоритет номер один в этом городе:
- полная карточка: все услуги отдельными позициями, часы, фото объектов,
  прайс, ссылки на посадочные страницы, реквизиты;
- работа с отзывами: отвечать на все, включая негативные, в течение суток;
- регулярное обновление фото.

**Яндекс.Бизнес / Яндекс.Карты:**
- заполненная карточка + подтверждённые права;
- раздел «Услуги» с ценами — участвует в колдунщике;
- фото; публикации/новости;
- сбор отзывов после каждого завершённого проекта.

**Google Business Profile** — заполнить, хотя доля меньше.

**Flamp** — карточка уже есть, привязана к бренду «Hygge Clean».
Если бренд меняется — карточку переименовывать, а не заводить новую:
рейтинг и отзывы не переносятся.

**Zoon, Yell, отраслевые рейтинги** — базовое присутствие, единый NAP.

**NAP-консистентность:** название, адрес и телефон должны быть **побуквенно
одинаковыми** во всех источниках, включая сайт. Разночтения снижают доверие
локальных алгоритмов.

## 7. Чего не делать

- **Не плодить страницы под районы** («уборка офисов Академический», «уборка
  офисов Уралмаш») — это классический переспам, за него понижают.
- **Не копировать текст между 11 посадочными** с заменой одного слова.
- **Не ставить AggregateRating** без настоящих отзывов — за накрутку разметки
  накладывают санкции.
- **Не использовать виджеты как единственный источник отзывов** — их содержимое
  не индексируется.
- **Не размещать ссылки на запрещённые в РФ платформы.**
- **Не оставлять пустые `alt`** — сейчас их 83 штуки.
- **Не оставлять ссылки вида `index.html#anchor`** — на внутренних страницах
  они ведут в 404.

## 8. Чек-лист технического SEO для приёмки

- [ ] `robots.txt` корректный, открывает сайт, ссылается на свой `sitemap.xml`
- [ ] `sitemap.xml` генерируется автоматически, только боевой домен, есть `lastmod`
- [ ] `canonical` на всех страницах, абсолютный URL
- [ ] `<html lang="ru">`
- [ ] Один вариант домена, остальные 301
- [ ] Все старые URL → 301 на новые, без цепочек
- [ ] Уникальные Title и Description на каждой странице
- [ ] Один `<h1>` на странице, иерархия H2–H3 без пропусков
- [ ] Осмысленные `alt` у всех изображений
- [ ] ЧПУ-адреса, латиница, дефисы
- [ ] Микроразметка: Organization, LocalBusiness, Service, FAQPage, BreadcrumbList
- [ ] Разметка валидируется без ошибок в обоих валидаторах
- [ ] Открытая и настроенная страница 404 с навигацией
- [ ] Скорость: Core Web Vitals в зелёной зоне на мобильных (см. файл 06)
- [ ] Нет `maximum-scale=1` в viewport
- [ ] Внутренняя перелинковка: с каждой услуги — на 2–3 смежные
- [ ] Хлебные крошки на всех внутренних страницах
- [ ] Тестовый домен закрыт авторизацией
- [ ] Права подтверждены в Яндекс.Вебмастере и Search Console
- [ ] Метрика: цели настроены, Вебвизор включён, UTM подставляются в формы
