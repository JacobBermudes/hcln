## Что это за папка

Это рабочая база знаний для редизайна сайта. Она собрана так, чтобы её можно было
загрузить в проект и использовать как единый источник правды: и для разработчика,
и для маркетолога, и для копирайтера, и для нейросети, которая будет помогать
писать тексты и код.

## Три вещи, которые нужно сделать до всего остального

1. **Заменить `robots.txt`** на боевом домене. Сейчас сайт закрыт от индексации
   директивой `Disallow: /`, а сам файл принадлежит другому проекту
   (магазин запчастей для спецтехники `center-part.ru`). Проверено внешним
   запросом: оба домена отказывают краулерам.
2. **Определиться с брендом**: «Hygge» или «Clean Office». Сейчас на одной
   странице соседствуют оба, а отзывы и карточки в справочниках привязаны
   к «Hygge Clean».
3. **Собрать фактуру** по списку из `OPEN-QUESTIONS.md`. Без реальных цифр,
   фото и клиентов новый сайт будет таким же безликим, как старый, только
   красивее.

## Статус источников

Рыночные данные в файле 02 собраны из открытых источников (BusinesStat,
NeoAnalytics/РБК, TAdviser, отраслевые обзоры, публичные прайсы конкурентов,
DK.ru, IDEM) в августе 2026 года. Оценки разных агентств расходятся — это
отмечено в тексте. Прайсы конкурентов — публичные витринные цены «от», реальные
контрактные ставки в B2B всегда ниже витринных.
